# Day 2 terminal ArgMax 최적화 증거

점검 일자: 2026-08-21 (Asia/Seoul)

## 구현 범위

- graph output의 유일한 producer인 표준 ONNX `ArgMax`만 외부화한다.
- ArgMax 결과에 graph consumer가 있거나 output·axis·tensor metadata 조건이 맞지 않으면 거절한다.
- 원본은 보존하고 `optimized-model.onnx`와 MCU용 `postprocess.json`을 별도로 만든다.
- 고정 seed 입력 10개로 baseline class index와 optimized logits의 ArgMax를 비교한다.
- validation 통과 후에만 candidate를 compile하며, compiler 지표가 실제로 개선된 경우만 채택한다.

## 선정 모델 스모크 테스트

공식 MobileNetV2 0.35 Food-101 128x128 QDQ 원본에 재현 가능한 스크립트로 terminal ArgMax를
붙였다. 원본 checksum과 라이선스는 `models/manifest.json`이 기준이며 파생 binary와 run
산출물은 `outputs/` 아래에 두어 Git에는 포함하지 않는다.

```powershell
.venv\Scripts\python.exe scripts\create_terminal_argmax_variant.py `
  models\downloads\mobilenetv2_a035_128_food101_qdq.onnx `
  outputs\day2\mobilenetv2_a035_128_food101_terminal_argmax.onnx

.venv\Scripts\arona.exe optimize `
  outputs\day2\mobilenetv2_a035_128_food101_terminal_argmax.onnx `
  --output-directory outputs\day2-runs
```

확인 결과는 다음과 같다.

| 항목 | 결과 |
| --- | --- |
| 파생 baseline SHA-256 | `c50a5dc876f65d7d2d3f568abfadc88744c5088a1ef479db7ee363e9101c141c` |
| baseline node 수 | 319 |
| rewrite 후 node 수 | 318 |
| ONNX Runtime 동등성 | 10/10 일치, 최대·평균 class-index 오차 0 |
| baseline live compile | 실패, exit code `4294967295` |
| candidate live compile | 실패, 같은 Core 버전 차단 |
| 최종 선택 | `baseline`, `accepted=false`, rewrite `rolled_back` |

실패 원문은 실제 toolchain fixture인
`tests/fixtures/backends/stedgeai/core_2_2_ir_version_failure/`에 경로를 치환해 보존했다.
ConMamba 두 fixture는 compiler 비교·롤백 로직을 검증하기 위한 기존 합성/과거 evidence로
구분한다.

```text
ST Edge AI Core v2.2.0-20266 2adc00962
INTERNAL ERROR: Your model ir_version 10 is higher than the checker's (9).
```

따라서 graph rewrite와 end-to-end 동등성은 실제 선정 모델에서 확인됐지만, compiler 개선값은
아직 주장할 수 없다. Core 4.0.0 설치 후 같은 명령을 다시 실행해 baseline/candidate report가
생성되어야 Day 2의 compiler-report gate가 완료된다.
